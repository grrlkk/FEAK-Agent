## 1. 복구 방법

```bash
# 한 파일만 내용 확인
git show 524ff90:feak_tc_docs/docs/PROJECT_CONTEXT.md

# 한 파일을 작업 트리로 복구
git checkout 524ff90 -- feak_tc_docs/docs/PROJECT_CONTEXT.md
```

작업 트리에는 정리 시점 원본을 담은 백업도 있다. 이 백업은 로컬 보관이며 커밋하지 않는다.

```bash
tar tf .cleanup_archive/2026-09-08-paper-docs/originals.tar
tar xf .cleanup_archive/2026-09-08-paper-docs/originals.tar -C /tmp/restore
```

## 3. 제거한 스크립트와 코드

실행이 끝난 일회성 분석·리포트 스크립트와, 사용하지 않는 MongoDB 계층이다.
